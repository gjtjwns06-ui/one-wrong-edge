# 재시작 실험을 위한 선행연구 재검토

확인일: 2026-11-25. 원 논문과 저자 공개 원문을 확인했다. 아래의 실험 설계 제안은 문헌에서 그대로 가져온 규칙이 아니라, 그 근거를 이 연구에 적용한 판단이다. 다른 논문의 성능을 이 프로젝트의 측정 결과로 사용하지 않는다.

## 실험에 반영할 다섯 가지

| 쟁점 | 원문에서 확인한 사실 | 이번 연구의 설계 판단 |
| --- | --- | --- |
| 접근 가능한 근거와 어려운 음성 | LeanDojo는 현재 정리보다 앞서 정의된 같은 파일의 명제와 import된 명제를 접근 가능한 근거로 제한한다. 같은 파일의 어려운 음성과 무작위 음성을 함께 사용한다. [LeanDojo §5](https://arxiv.org/html/2306.15626v2) | Metamath의 원문 순서에 맞는 후보만 허용한다. 자기 정리·동일 서명·미래 정리를 제외하고, 순위 특징의 인용 수와 탐색 지지에도 미래 증명이 섞이지 않는지 별도로 검사한다. 어휘상 가까운 비인용 명제와 무작위 비인용 명제를 함께 사용한다. |
| 새로운 분할의 의미 | LeanDojo는 학습에서 사용하지 않은 전제에 의존하는 정리를 평가하는 별도 분할을 제공한다. Dwork 등의 연구는 결과를 보며 시험 자료를 반복 재사용하면 시험 집합 자체에 과적합할 수 있음을 분석한다. [LeanDojo](https://arxiv.org/abs/2306.15626), [Adaptive Data Analysis and Holdout Reuse](https://arxiv.org/abs/1506.02629) | 기존 질문을 새 난수로 다시 나누는 것만으로 독립 시험이 생기지 않는다. 이전 학습·시험 질문과 겹치지 않는 관련 주제 또는 원문 구간을 확보하고, 선택 전에 시험 목록을 고정한다. 같은 원문 라이브러리에서 나온 새 구간이라는 한계도 기록한다. 불가능하면 재분할 결과를 개발 평가로 명시한다. |
| 텍스트와 증명 구조의 결합 | Petrovčič 등의 연구는 Lean의 상태–전제와 전제–전제 의존 그래프를 구성하고 텍스트 표현과 구조 정보를 결합한다. 따라서 증명 의존 관계를 순위에 쓰는 발상 자체는 선행연구에 있다. [Combining Textual and Structural Information for Premise Selection in Lean](https://arxiv.org/html/2510.23637v2) | 어휘 검색, 텍스트 특징만 학습한 순위, 구조 특징을 더한 순위를 같은 후보·출력 예산에서 비교한다. 그래프 후보 확보의 효과와 그래프 순위 특징의 효과를 분리한다. GNN을 구현하지 않았다면 해당 논문을 재현하거나 능가했다고 주장하지 않는다. |
| 오류의 위치와 실제 피해 | CS-RAG는 불필요한 관계와 정보 누락을 구분하고, 질문 주변의 국소 오류와 전체 그래프 오류를 따로 주입한다. 전역 오류는 필요한 경로와 덜 교차하여 악화가 완만할 수 있음을 보고한다. [Don't Worry About Quality, §4.2·Appendix D](https://arxiv.org/html/2603.14828v3) | 전역 무작위 오류·어휘상 유사한 오류·누락을 구분한다. 필요하면 정답을 읽지 않고 기본 검색의 관측 탐색 관계 주변에 오류를 넣는 국소 스트레스 조건을 추가한다. 정상 대비 실제 피해, 잘못된 관계 노출률, 삭제 후 회복을 먼저 측정한다. 국소 스트레스의 개선을 자연 발생 오류 전반으로 일반화하지 않는다. |
| 인용 회수와 증명 성공의 구분 | LeanDojo는 검색 지표와 실제 정리 증명 지표를 따로 평가하며, 사람이 작성한 증명은 최종 성공 경로만 담는다는 한계를 설명한다. LeanSearch v2도 전체 정리에 대한 전제 집합 검색과 고정된 증명 루프에서의 성공을 분리한다. [LeanDojo §6·F](https://arxiv.org/html/2306.15626v2), [LeanSearch v2](https://arxiv.org/abs/2605.13137v2) | 하나의 저장된 증명에 인용된 명제는 관측된 증명 사용 정답이다. 모든 가능한 증명에서의 논리적 필수성을 뜻하지 않는다. 직접 인용 Recall과 전체 인용 회수를 보고하고, 새 증명 생성·형식 검증을 실행하지 않았다면 그 성공률을 주장하지 않는다. 원문에 없는 인용 귀속과 거짓 수학 명제도 구별한다. |

## 새로움과 비교의 한계

형식 수학의 전제 선택, 텍스트–의존 구조 결합, 질문별 그래프 탐색, 오류가 있는 그래프에서의 견고한 검색에는 이미 선행연구가 있다. 이번 연구가 추가로 확인해야 할 대상은 **개선된 증명 근거 검색기를 고정한 뒤에도, 어떤 질문에서 어떤 관계의 억제가 도움이 되는가**라는 조건부 개입 효과와 그 실패 조건이다. 간선을 잘못된 귀속으로 분류하는 정확도와 검색 효용을 개선하는 능력을 따로 평가해야 한다.

위 논문들의 데이터·입력·계산 예산은 이 프로젝트와 다르다. 문헌 표의 성능 수치를 직접 대결 표로 옮기지 않는다. 실제로 구현한 비교군만 실험 결과의 비교 대상으로 삼는다. 완전한 신규성 조사나 자연어 수학 전반의 일반화 검증을 마쳤다는 의미도 아니다.
