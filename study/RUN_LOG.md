# 연구 진행 기록

기준일: 2026-11-23.

## 시작 상태

작업 폴더에는 `One_Wrong_Edge_Paper_Draft_REDOWNLOAD (2).md`만 있었다. 기존 실험 코드·데이터·로그·성능 결과는 없었다. 초안의 성능 수치를 실제 결과로 상속하지 않았다. 원문 외의 로컬·외부 작업 환경 전체를 검색했다는 주장은 하지 않는다.

## 범위 결정

초기에는 Metamath 전체 라이브러리의 접근성과 증명 의존 추출 가능성을 확인했다. 원문과 CC0 이용 조건을 고정 커밋에서 확보하고 압축 증명 파서와 추가 증명 검사를 실행했다.

사용자가 전체 라이브러리는 너무 넓다고 수정했다. 이에 따라 **성능 실험 시작 전에** 전체 라이브러리 평가를 취소하고 집합·관계·함수·유한집합 및 그래프의 보행·경로·오일러 경로로 한정했다. 다른 수학 분야나 다른 형식 데이터베이스에 대한 성능 실험은 실행하지 않았다. 범위 밖 직접 인용은 경계 근거로만 보존하고 재귀적으로 확장하지 않았다.

정확한 단원 목록과 평가 규칙을 `configs/scoped_v1.json`, `RESEARCH_DESIGN.md`에 기록하고 해시를 고정했다. 외부 등록된 사전등록은 아니다. 선행연구가 이미 premise selection·graph filtering·query-aware traversal을 다룬다는 사실을 확인하고, 그 자체를 새 기여라고 주장하지 않았다.

## 실제 실행

1. 원문 가정과 변수 제약을 보존해 핵심 명제 3,843개와 종단 경계 근거 2,773개를 구성했다.
2. 적격 형식 질의 3,684개를 만들고 중복 제거·블록 분할·검증/시험 증명 출발 간선 숨기기를 수행했다.
3. 정상 및 무작위20%-시드17의 학습·검증 개입 효과만으로 모델과 임계값을 선택했다. 시험 효과 생성 전에 선택 파일을 저장했다.
4. 시험 질문 567개/25개 원문 블록에서 7개 조건, 13개 정책, 3개 출력 예산을 평가했다. 3,969개 그래프-질문 사례와 154,791개 측정행을 보존했다.
5. 단일 삭제 87,806개의 실제 효과, 최대3개 삭제 후 재검색, 반복 오류 시드 평균, 블록 bootstrap, 특징 제거 비교, 실패 사례를 분석했다.
6. 별도 의미 검사로 최대6개 정점의 단순 무향 그래프 33,867개를 전수 검사하고 오일러 조건 누락의 반례를 남겼다.

## 사후 변경의 구분

최초 결과에서 실제 반환 문서 수·형식 토큰 차이를 확인한 뒤, 같은 문서 수와 토큰 상한을 쓰는 어휘 검색 비교를 **사후 기술 분석**으로 추가했다. 이유와 고정 규칙은 `FOLLOWUP_BUDGET_AUDIT.md`에 남겼다. 원래 결과·모델·임계값·분할은 변경하지 않았다.

그림의 범례 겹침을 고쳤고 실패 사례 목록에서 같은 질문의 반복 오류 조건이 독립 사례처럼 나열되지 않도록 서로 다른 질문을 선택했다. 이는 그림·사례 제시 변경이며 실험 결과나 모델 조정이 아니다.

## 품질 확인

자동 검사 7개를 통과했다. 별도 BFS로 250개 저장 사례의 단일 삭제 5,591개와 학습 정책 출력 750개를 재실행해 일치시켰다. 원래 프로토콜·데이터·실행 코드 해시, 출처 일치, 숨긴 증명 경계, 출력 상한, 지표 범위, 어휘 검색의 오류 그래프 불변성, 출처 확인의 정상 그래프 복원도 확인했다. 독립 연구자의 검토나 외부 재현을 완료했다는 주장은 하지 않는다.

## 발견과 연구 판단

같은 간선의 질문별 부호 변화와 정확성/검색 효용의 구분은 실제 관측했다. 최대3개 학습 삭제의 평균 Recall@20 이득은 작고, 미관측 오류 시드에서는 구간이 0을 포함했다. 출처 확인보다 일반적으로 낫다는 근거도 없다. 출력 예산 40에서는 이득이 사라지고 전체 직접 인용 회수율도 개선되지 않았다. 따라서 논문의 주장을 보편적인 학습 개선에서 **제한된 범위의 개입 진단과 실패 분석**으로 수정했다.

전역 어휘 검색의 우위는 같은 출력 상한에서만 뚜렷했고 실제 문서 수·형식 토큰을 맞추면 비교가 달라졌다. 이 차이를 숨기지 않고 별도로 보고했다. 그래프 경계와 증명 숨기기로 생긴 빈 이웃은 삭제 정책이 해결하지 못하는 실패 조건으로 남겼다.
