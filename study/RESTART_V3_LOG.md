# restart-v3 실행 기록

2026-11-25. 사용자의 전체 재실행 요청에 따라 새 실험 계획과 별도 산출물 경로를 만들었다. 기존 결과 수치를 새 결과로 재사용하지 않는다.

설계 검토에서 기존 시험 재사용, 시험 인용을 이용한 경계 색인 선정, 전체 문서 TF-IDF 적합, 순위 모델과 정책 모델 학습 정답의 중첩 가능성을 중점 점검했다. 새 설계는 정확한 이전 색인 서명이 없는 신규 주제 시험, 공개 증명만 이용한 경계, 공개 문서 TF-IDF, 별도 정책 학습 분할을 사용한다. 관련 문헌의 원문을 확인한 근거와 신규성 제한은 `LITERATURE_V3.md`에 남겼다.

고정 원문을 다시 파싱해 지역 증명 검사48,420개를 통과했다(60.5초). 이는 독립 인증된 상류 검증기가 아니라 명시적 가정·대입·변수 제약과 최종 증명 스택을 확인하는 연구용 검사다. 새 핵심4,643개와 공개 경계2,223개, 총6,866개 명제 및 공개 간선29,862개를 생성했다.

순위 학습2,306개/86블록, 정책 학습735개/26블록, 검증639개/28블록, 신규 시험582개/38블록이다. 신규 시험은 이전 색인/질문과 서명 중복0개이며 주제별로 순서26·관계/함수 후속70·동치관계121·문자열282·관계 폐포83개다. 색인 밖 시험 인용597/9,752개를 분모에서 제외하지 않았다. 질문별 평균 색인 밖 비중은5.089%다.

독립 자료 감사에서 이전 배포186개 파일 보존, 정답 원문 재구성, 공개 경계 출처2,223개, 가림2,205개 출발 노드, 분할/서명 비중첩이 통과했다. 새 검사6개와 기존 검사14개, 총20개가25.98초에 통과했다. 이 시점에는 신규 시험 성능을 아직 계산하지 않았다.

검증 후보 선택에서 hybrid64_h2를 고정했다. 검증 후보 포함률71.26%, 후보 내 Recall@20 상한70.82%였고, 같은256개 어휘 후보 포함률은44.17%였다. 순위 선택은 boost_31이며 검증 Recall@20은38.16%, 같은 후보의 텍스트 특징 순위 모델37.85%, 어휘 순위24.24%였다. 텍스트 비교군도 그래프로 만든 같은 후보 안에서 순위만 바꾸므로 완전히 그래프를 쓰지 않는 검색과 다르다.

최종 순위 모델을 고정하고 별도 정책 학습735개 질문×3조건에서 개입52,217개를 새로 계산했다. 양의 효과183개, 음의 효과304개, 0효과51,730개였다. 개별 효과를 더하지 않고 검증에서 최대1/3/8개를 실제로 함께 억제했다. 스케일러 계산 중 상수 열의 분산이 약−3.47e−35로 반올림되어 sklearn 경고가 있었지만, 스케일·평균·세 모델 예측의 유한성을 확인했다(`model_numeric_checks.json`).

별도 코드 검토에서 질문15개 조건 사례에 대해 후보 한도를256→64→256으로 복원한 후보·특징·간선이 정확히 같음을 확인했다. local8_s439는 관측 수식과 탐색만 사용하는 결정적 조건명이며439를 독립 난수 반복으로 세지 않는다. 직접 비교군과 출처 확인은 자기 후보·탐색량을 저장하며, 학습/무작위/오라클 개입의 후보 카운터는 삭제 전 기본 후보다. 정책의 추가 재검색 비용은 이 카운터에 합산하지 않는다.

검증은 효용 HGB 최대1개/임계값0.002, 거짓 귀속 HGB 최대1개/임계값0.8을 선택했다. 검증 추가 효과는 각각+0.0229pp와+0.0190pp였다. 최대1개는 사전 제한이 아니라1/3/8개 비교의 선택 결과다. 모델·데이터·코드·설정·선택21개 파일을 잠근 뒤 신규 시험을 시작했다.

신규 시험582개×8조건×12방법×출력예산3개=167,616행을 완료했다. 시험 단계 wall time은683.86초이며, 오라클·개입 효과 정답 생성과 여러 비교군 계산까지 포함한다. 실제 추론 지연과 다르다. 정상 Recall@20은 기존 지역 알고리즘14.46%, 어휘19.56%, 그래프 특징 제외 정적 정보 학습25.22%, 전체 특징 증명 인용 학습26.41%였다. 주 순위−기존 지역 차이는+11.957pp [8.773,15.199], 같은 후보의 정적 특징 학습 대비+1.194pp [0.236,2.164]였다.

사전 지정한 전역20% 오류 평균에서는 기본26.1678%→효용 정책26.1741%, 추가+0.0063pp [−0.0116,+0.0276]였다. 거짓 귀속 정책의 추가 효과도+0.0035pp [−0.0144,+0.0261]였다. 일반적인 추가 이득을 확인하지 못했다. 누락 전이 조건의 효용 정책은−0.0836pp [−0.1569,−0.0155]로 악화됐다. 이 구간은 고정 모델/원문 블록에 조건부인 기술적 구간이며 다중 비교를 보정한 확정 검정은 아니다.

정상 근거 질량은 회수26.41%, 색인 밖5.09%, 후보 밖40.10%, K20 용량0.30%, 후보 안 순위 손실28.10%로 분해됐다. 전역 오류에서 거짓 간선을 실제로 지난 질문×시드 비중은92.23%였지만 단일 간선 개입은 대체로0효과였다. 제한된24개 후보의 단일 삭제 오라클 여지는 전역 평균+0.4385pp로 양수였으며, 학습 정책이 이를 회수하지 못했다. 오라클은 일반적인 다중 개입의 상한이 아니다.

독립 전체 감사는56.85초에 통과했다. 이전186개 파일·잠금21개, 공개 문서4,661개의 TF-IDF 독립 재적합, 모든167,616행의 순위 기반 지표 재계산, 모든 후보/출력 적격성, 미래 출발 간선 제거 불변48회, 물리적 단일 삭제132회, 정답 없는 추론 및 선택 정책 물리적 재실행96회를 확인했다. 선택 정책 재실행33회에서 실제 삭제가 있었다. 고유 질문×조건48개 타이밍의 중앙값은 기본19.31ms, 효용24.86ms, 귀속 분류27.29ms였다. 색인/모델 적재와 사후 정답 계산을 제외하며 특징 캐시는 예열될 수 있다.

실제 CLI 예시 `trrelssd`의 정상 무삭제 검색을 실행해20개 근거·원문 링크 반환을 확인하고 `cli_example.json`에 남겼다. 연구용 두 그림을 시각 점검하고 범례가 데이터를 가리지 않게 위치를 고쳤다. 예측 코드와 시험 선택은 바꾸지 않았다. 실패 사례·분류 분포 이동·원문 출처가 완전할 때 직접 확인이 가능한 한계와 실제 답변/새 증명 미평가를 결과 및 개정 초안에 기록했다.
