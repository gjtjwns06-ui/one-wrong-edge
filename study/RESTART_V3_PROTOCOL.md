# 처음부터 다시 실행하는 연구 계획

2026-11-25 · restart-v3. 이전 결과는 가설과 코드 검토 자료로만 사용한다. 기존 v1/v2의 데이터·모델·선택·결과 파일을 덮어쓰지 않는다. 새 원문 파싱, 분할, 색인, 오류 그래프, 학습, 개입 효과, 검증 선택, 시험을 별도로 실행한다. 실험 수치는 `configs/restart_v3.json`, 범위는 `configs/restart_v3_data.json`에 고정한다.

## 자료와 신규 시험

같은 CC0 Metamath 고정 커밋을 사용하되, 전체 라이브러리는 원문 검증에만 사용한다. 주 실험은 집합·관계·함수·유한집합과 그래프 경로/오일러 주제다. 신규 전이 시험은 이들과 연결되는 문자열, 관계의 반사·추이 폐포, 동치관계, 부분·전순서, 관계/함수 후속 절에서 고른다. 기존 색인의 모든 canonical signature와 겹치는 시험 질문을 제외한다. 이는 이전에 검색 문서로도 사용하지 않은 정확한 서명 기준의 신규성이다. 같은 라이브러리의 유사한 정리와 의미적 독립성까지 보장하지 않는다. 이전에 전체 원문이 파싱·검증된 사실을 숨기지 않는다.

기존 핵심 주제의 원문 블록(32명제)을 새 시드20261125로 rank_train60%, policy_train20%, validation20%로 나눈다. 신규 절은 test로만 사용한다. 순위 모델은 rank_train만 학습한다. 이 모델을 고정한 뒤 별도 policy_train 질문에서 개입 정답을 만든다. 검증은 후보·모델·정책 선택에 사용하고, 모든 선택을 해시로 잠근 뒤 처음 신규 시험을 평가한다. 신규 시험 성능에 따라 설정을 다시 선택하지 않는다.

신규 주제의 모든 증명 출발 간선과 policy_train/validation 서명의 모든 별칭 출발 간선을 숨긴다. 검색 문서 집합은 사전 선택한 핵심 주제 명제와 **공개된 배경 증명에서만** 참조한 단일 단계 경계로 구성한다. 시험 증명의 의존 목록으로 경계를 넓히지 않는다. 색인 밖 정답도 회수율의 분모에 남기고 별도로 집계한다. TF-IDF는 공개 배경/순위 학습 문서에만 적합하며, 시험·정책·검증 문서는 변환만 한다.

정답은 지정된 증명에서 실제로 사용한 직접 `|-` 인용이다. 모든 증명의 필수 조건, 거짓 수학 명제 판별, 자연어 답변 정확성이나 새 증명 성공률과 구분한다. 후보는 질문보다 앞선 명제이며 자기/동일 서명을 제외한다. 인용 prior도 질문보다 앞선 공개 증명만 센다. 모델 자체를 시간순으로 온라인 학습한 실험은 아니다.

## 후보 확보와 순위

같은256개 후보 한도에서 세 가지 어휘·관측 인용·확장 가능 시드 조합을 검증한다. 후보 내 Recall@20 상한, 후보 포함률, 적은 탐색량 순으로 선택한다. 어휘 전역256개와 기존4시드/2단계 지역 검색을 별도 비교한다. 기존 지역 검색과는 계산 예산이 다르므로 같은 비용의 우월성으로 해석하지 않는다.

42개 관측 특징의 Logistic Regression/gradient boosting과 그래프 특징을 제외한 텍스트 모델을 비교한다. 두 모델은 같은 후보에서 순위를 매긴다. 양성은 실제 학습 인용, 음성은 가까운 비인용32개+무작위32개이며 질문·클래스 가중치를 균형화한다. 검증 Recall@20과 단순성을 기준으로 주 검색기를 선택한다. 64후보의 추가 결과는 고정 모델에 대한 예산 이동 검사이며, 64에서 재학습/최적화한 동등 모델로 주장하지 않는다.

## 간선 개입과 오류 조건

원문 배경 증명에 없는 관계를 넣는 것은 **잘못된 증명 사용 귀속**이며 명제 자체의 거짓을 의미하지 않는다. 전역 random/hard20% 조건은 학습101, 정책211, 검증307, 시험401/409·419/421의 시드를 분리한다. clean도 정책 선택에 포함해 정상 관계 억제의 손해를 반영한다. 시험의 missing20%와 mixed(10%누락+10%추가)는 학습하지 않은 오류 유형 전이다. realized rate/실패 제안/관측 오류 노출량을 기록한다.

별도 local8 스트레스는 정상 무개입 탐색에 나타난 출발 노드에 최대8개 거짓 귀속을 추가한다. 출발·목적지는 관측 수식/탐색/원문 순서로만 선택하며 정답·효과를 보지 않는다. 모든 시험 질문을 포함하며 주입 불가능 사례도 남긴다. 전역 오류의 주 결과와 합치지 않는다.

고정 순위 모델의 policy_train 질문에서 최대24개 관측 탐색 간선을 골라 각각 삭제 후 후보와 특징·순위를 재계산한다. 반은 예측 목적지 관련도, 반은 표집이며 정답으로 선택하지 않는다. 부호 있는 Recall@20 효과 회귀와 거짓 귀속 분류를 따로 학습한다. 최대1/3/8개 삭제 및 보류를 검증 실제 재검색으로 선택한다. 다중 효과를 단일 효과의 합으로 대체하지 않는다.

비교군은 삭제 없음, 같은 행동 수의 무작위 삭제, 효용 ML, 거짓 귀속 ML, 출처 확인, 최대24개 후보의 단일 삭제 오라클이다. 출처 확인은 더 강한 공개 증명 귀속 정보를 쓰며 행동 수 일치 비교가 아니다. 단일 오라클은 다중 정책의 상한이 아니다. 삭제 효과 대부분이0일 가능성을 연구 결과로 인정하고 양/음/0 빈도와 오라클 여지를 공개한다.

## 평가와 해석

주 지표는 실제 직접 인용 Recall@20이다. 핵심 추가 ML 비교는 두 전역20% 오류 유형의 질문별 평균이다: random두 시드 평균과 hard두 시드 평균을 같은 비중으로 평균한다. clean, 누락/혼합 전이, 국소 스트레스는 각각 별도로 보고한다. 같은 질문의 시드를 먼저 평균하고 원문 블록 bootstrap2,000회로95% 기술적 구간을 구한다. 반복 조건이나 간선을 독립 질문으로 세지 않는다.

후보 포함률/상한, nDCG, 완전 인용 회수, K10/40, 주제별 결과, 색인 밖 정답, 오류 노출·실행·악화 비율, 실제/거짓 귀속 억제, 시간과 반환 형식 토큰을 함께 보고한다. 고정 모델 조건부 구간이며 전체 학습 변동·모든 선택·다중 비교를 포함한 확정 검정은 아니다. 모델에 골드·주입 표시·사후 효과를 특징으로 전달하지 않는지와, 물리적 삭제 후 재실행 일치를 독립 점검한다.

복잡한 방법이 단순한 검색보다 좋지 않거나 간선 ML이 추가 이득을 내지 못하면 그대로 보고한다. 결과를 본 뒤 수정이 필요하면 기존 시험을 개발 자료로 바꾸고 새 검증을 요구하며, 성공처럼 보이도록 수치를 선택하지 않는다.
