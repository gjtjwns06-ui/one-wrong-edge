# 검색기 개선 → 증명 인용 순위 학습 → 간선 제거 ML의 추가 효과

2026-11-23. `sequential-v2` 실행 전에 고정한다. 이전 시험 결과와 실패 진단을 보고 설계한 후속 개발 실험이므로 기존 시험 집합을 새로운 독립 검증 자료라고 주장하지 않는다. 기존 `scoped-v1`과 진단 산출물은 변경하지 않는다.

## 공통 자료와 순서

기존 핵심 명제·종단 경계 근거, 형식 질문, 정답 인용, 학습/검증/시험 원문 블록 분할과 7개 관측 그래프를 그대로 사용한다. 검증·시험 증명 출발 간선을 공개하지 않고, 질문보다 뒤의 명제나 동일 질문 서명을 검색하지 않는다. 범위 밖 노드·간선을 확장하지 않는다. `configs/sequential_v2.json`이 수치 설정이다.

1. 학습·검증 자료에서 후보 확보 방식을 고른 뒤 고정한다.
2. 그 후보에서 실제 학습 증명 인용을 정답으로 순위를 학습하고 검증에서 선택한 뒤 고정한다.
3. 고정된 새 검색기에 대한 간선 제거 효과를 새로 측정해 ML을 학습·검증한다. 모든 선택을 저장한 뒤 기존 시험 집합에서 세 단계와 비교군을 함께 평가한다.

단계1·2·3의 시험 결과를 보고 해당 단계의 설정을 다시 고르지 않는다. 검증 자료를 단계별로 재사용하므로 선택 불확실성과 시험 집합 재사용의 한계를 명시한다.

## 1단계: 후보 확보

어휘 상위64/128개를 기본 후보로 보존한다. 어휘 상위128개 안에서 현재 출발 관계가 있는 명제16개와 어휘 상위8개를 시드로 사용한다. 고정4개 시드가 모두 막히는 현상을 줄이되, 확장 불가능한 명제도 검색 문서로는 허용한다.

기존 관측 그래프의 과거 인용 수 상위16/32개도 후보로 확보한다. 인용 수는 질문보다 앞선 **배경 증명**의 관측 간선에서만 계산하며 현재 질문의 정답이나 미래 증명을 세지 않는다. 이는 일반 논리 보조정리의 후보 누락을 줄이기 위한 입력 그래프 기반 통계다.

공개된 증명 사용 방향으로 1/2단계를 탐색한다. 선택·추적할 전이는 최대2,048개이고 최종 후보는 최대256개이다. 시드 유사도와 출발 차수로 가중한 탐색 지지량으로 그래프 후보를 우선한다. 후보 수·전이 수·실제 시간과 최종 출력 수를 기록한다.

검증의 정상 및 무작위20%-시드17에서 후보 내 완벽한 재정렬의 Recall@20 상한을 최대화하는 설정을 선택한다. 동률에는 후보 포함률, 적은 탐색량을 차례로 사용한다. 동일 후보 수 상한의 전역 어휘 후보256개와도 비교한다. 넓은 후보가 이후 순위 학습에 주는 기회를 평가하며, 후보만 늘린 것을 최종 검색 개선으로 부르지 않는다.

## 2단계: 실제 증명 인용을 예측하는 순위 모델

각 (질문, 후보 명제)에 대해 원문 증명의 직접 인용 여부를 학습 정답으로 삼는다. 일반적인 논리적 필요충분성이나 모든 가능한 증명의 필수 관계와 다르다. 필수 가정·변수 제약을 문서에 보존하고 결론·가정 간의 정렬, 기호 유사도, 명제의 형식적 역할·길이·가정 수, 관측 그래프의 과거 인용·경로 지지 등을 특징으로 사용한다.

특정 명제/질문 식별자, 정답 관계, 주입 표시, 정상 그래프 비교, 시험 증명은 특징으로 쓰지 않는다. 문서의 관측 가능한 정의/공리 형식은 허용하되 개별 명제 ID의 임베딩은 학습하지 않는다. 후보 수 대비 음성이 많으므로 모든 양성과 어휘상 가까운 음성32개 및 나머지 무작위 음성32개를 학습한다. 질문과 양/음 클래스의 총 가중치를 균형화한다.

정규화 Logistic Regression과 histogram gradient boosting을 비교한다. 모델 선택은 검증 Recall@20, 동률에는 전체 인용 회수율·간단한 모델을 사용한다. 어휘 순위, 과거 인용 수 순위, 동일 후보의 비학습 혼합 점수를 함께 비교해 복잡성의 가치를 확인한다. 순위 모델에는 시험 및 검증 질문의 정답을 학습시키지 않는다.

## 3단계: 새 검색기 위의 간선 제거

후보 확보·순위 모델을 고정한 뒤 삭제할 때마다 후보·그래프 특징·순위를 **실제로 다시 계산**한다. 이전 검색기에서 만든 개입 정답을 재사용하지 않는다. 출발점 재선택과 후보 제한 때문에 삭제 후 후보가 단순 부분집합이 아닐 수도 있으므로 이전 검색기의 단조성 논의를 그대로 적용하지 않는다.

질문별 관측 탐색 관계에서 최대24개를 선택한다. 현재 예측 순위가 높은 목적지로 가는 관계 절반과 나머지의 결정론적 표집 절반을 사용하며, 정답·주입 표시로 고르지 않는다. 주 지표 Recall@20의 부호 있는 삭제 효과를 회귀하고 삭제 없음/최대1개/3개 일괄 삭제를 검증에서 선택한다. 3개 삭제는 개별 효과를 합산하지 않고 최종 재검색으로 평가한다.

학습 질문에 과적합한 순위 모델로 개입 정답을 만들지 않도록 학습 원문 블록의 3-fold out-of-fold 순위 모델을 사용한다. 각 fold에서는 그 fold 질문군의 출발 증명 간선도 추가로 숨기고, 해당 fold 정답을 쓰지 않은 순위 모델로 그 질문들의 개입 효과를 계산한다. 선택한 모델 종류·설정은 변경하지 않는다. 배포 시 전체 학습 자료로 적합한 순위 모델과 OOF 개입 효과로 적합한 정책을 사용한다. OOF 모델과 최종 모델의 학습 규모 차이는 한계로 남긴다.

추가로 거짓 귀속 여부를 분류하는 모델도 같은 관측 특징으로 학습해 효용 회귀와 구분한다. 주입 표시는 이 분류의 **학습 정답으로만** 사용하며 특징에는 포함하지 않는다. 잘못된 관계를 잘 찾는 것과 실제 회수율을 높이는 것을 따로 평가한다.

비교군은 새 검색기 그대로, 개수 일치 무작위 삭제, 비학습 질문 관련도 삭제, 효용 학습 삭제, 거짓 귀속 분류 삭제, 원문 배경 증명으로 직접 출처를 확인한 검색, 동일 후보의 단일 효용 오라클이다. 출처 확인은 더 강한 출처 접근을 사용하고 전역 정리가 가능하므로 같은 행동 예산의 ML 비교로 해석하지 않는다. 실제/거짓 귀속을 삭제한 비율과 악화 사례도 보고한다.

## 평가·검증·산출물

세 단계의 질문별 paired Recall@20 변화, 후보 포함률과 상한, nDCG, 전체 인용 회수율, Recall@10/40, 실제 반환 수와 형식 토큰, 탐색량·실행 시간, 삭제율·개선·악화율을 보존한다. 무작위20%의 시드는 질문 내 평균하고 원문 블록 bootstrap 2,000회로 기술적95% 구간을 계산한다. 다중 비교나 모든 학습 변동을 포함한 확정적 유의성 주장으로 쓰지 않는다.

평가 코드가 골드·주입 표시를 예측 특징에 전달하지 않는지, 미래·자기 명제가 후보에 들어오지 않는지, OOF 질문 블록이 순위 학습과 겹치지 않는지, 삭제 후 재검색 결과가 독립 재실행과 맞는지 확인한다. 기존 파일 해시를 유지하고 새 코드·설정·선택 영수증·모델·원시 결과·실패 사례·분석·개정 논문을 별도 버전으로 남긴다.
