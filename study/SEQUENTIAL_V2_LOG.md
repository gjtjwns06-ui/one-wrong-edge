# Sequential-v2 연구 기록

2026-11-23. 기존 시험과 진단을 바탕으로 한 후속 개발 실험이다. 동일 시험 자료의 재사용을 공개하며 독립적인 새 벤치마크 결과라고 주장하지 않는다.

설계와 설정을 먼저 작성하고 후보 확보·순위 학습·간선 제거의 순서로 선택한다. 구현 기능 점검에는 학습 질문 `dfss3`와 이미 진단서에 공개된 시험 사례 `eulerpathpr`를 사용했다. 후자는 전체 시험 평가나 설정 선택에 사용하지 않았으며, 이 점검 뒤 후보 설정을 바꾸지 않았다. 단계별 전체 시험 성능은 모든 모델·정책 선택 후에 계산한다.

1단계 검증에서 `hybrid64_h2`를 선택했다. 후보 포함률62.24%, 후보 내 Recall@20 상한61.55%였고, 같은256개 어휘 후보의 포함률은38.29%였다. 2단계 검증에서 `boost_31`을 선택했다. Recall@20은30.53%였고 어휘 순위20.25%, 고정 혼합 점수23.00%와 비교했다. 시험 결과로 이 선택을 바꾸지 않는다.

3단계 계산 중 실행 최적화를 적용했다. 완전히 같은 후보 특징에 대한 예측과 질문 독립적인 명제쌍 유사도를 재사용하고, 인용 수0인 항목은 양수 인용 prior 후보 정렬 전에 제외한다. 작은 예측 배치의 OpenMP 스레드는1개로 제한하고 모델 적합은4개를 유지했다. 완료한 OOF0의 원래 후보·예측값과 완전히 같음을 확인하는 검사, 실제 그래프 삭제와 억제의 일치 검사 등13개가 통과했다. 완료한 분할과 이미 학습된 모델을 보존하고 해당 실행 프로세스만 재시작했다. 이는 실행 최적화이며 후보 규칙·학습 정답·모델 설정·선택 기준의 변경이 아니다.

이후 독립적인 질문별 개입 정답 계산을 CPU 프로세스3개로 나눴다. 질문 순서와 난수 시드는 유지하고, 직렬 계산과 병렬 계산의 후보·특징·예측·효과가 완전히 같은지 확인했다. 총14개 검사가 통과했다. 프로세스 수는 실험 표본 수나 독립 반복 수로 세지 않는다. 완료된 OOF0/1과 OOF2 순위 모델을 보존했고, 미완료 분할의 개입은 다시 계산했다.

최종 실행은 시험 질문567개, 조건7개, 방법19개, 출력 예산3개로 완료했다. 총226,233개 측정 행을 저장했다. 정상 조건 후보 포함률은 기존27.44%에서68.46%로, 최종 직접 인용 Recall@20은19.49%에서38.02%로 바뀌었다. 같은 후보의 어휘 순위 대비 학습 순위의 차이는+14.637pp, 원문 블록 bootstrap95% 구간은[+11.998,+17.505]pp였다.

새 검색기 위 효용 ML≤3의 추가 변화는 미관측 무작위 오류 두 시드에서+0.125pp,95% 구간[-0.175,+0.447]pp였다. 오류 분류≤3은 해당 조건에서 삭제 관계 중90.86%가 거짓 귀속이었지만 Recall@20 변화는0이었다. 보조 일괄 필터는 검증에서 삭제 보류가 선택되어 시험에서도 삭제하지 않았다. 작은 일부 조건의 양의 수치로 일반적 추가 이득을 주장하지 않는다.

기존 배포70개 파일과 예측 코드·모델 선택 해시가 유지됨을 확인했다. OOF3분할 감사, 실제 그래프를 수정한 단일 삭제126회 및 추론/정책210회 재실행이 통과했다. 별도 추론42개에서 기본 순위 검색과 효용≤3 정책의 중앙 지연은 각각13.63ms와22.51ms였다. 사후 효과 정답 계산과 모델·색인 로딩은 제외했다.

최종 분석 점검에서 반복 시드의 실행·개선·악화 사건을 먼저 개별 사례에서 계산한 뒤 질문별 평균하도록 집계 정의를 명확히 했다. 시드 평균 삭제 수가0보다 큰지를 이용한 합집합 비율로 집계하지 않는다. 고정된 순위·개입 결과와 Recall·효과 구간·삭제 정밀도는 바뀌지 않았다. 모든 수치 유한성·출력 상한·사건 비율과 평균 삭제 수의 일관성 검사가 통과했다. 기존 시험 재사용이라는 해석 제한을 결과와 개정 논문 모두에 표시했다.
