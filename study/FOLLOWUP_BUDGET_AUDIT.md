# 사후 추가 분석: 실제 반환 예산 맞추기

2026-11-23, 최초 `scoped-v1` 시험 및 분석 완료 후 작성.

최초 결과에서 전역 어휘 검색은 최대 K개를 반환하지만 지역 그래프는 도달 문서가 적어 K개보다 적게 반환하는 경우를 확인했다. 이는 같은 출력 상한만으로 실제 문서·토큰 예산이 일치하지 않는다는 초기 설계의 주의점에 해당한다. 결과 해석의 혼동을 줄이기 위해 아래 비교를 **사후 기술적 분석**으로 추가한다. 최초 실험 결과·모델·임계값·분할·주 지표는 수정하지 않는다.

1. 문서 수 일치: 각 질문·그래프·K에서 지역 그래프가 실제 반환한 N개만큼 전역 어휘 순위 상위 N개를 반환한다.
2. 토큰 상한 일치: 같은 지역 그래프 결과의 형식 토큰 수를 상한으로 사용한다. 전역 어휘 순위를 순서대로 읽고 남은 예산에 들어가는 문서만 선택하며 최대 K개를 반환한다. 문서를 자르지 않는다.

학습이나 최적 임계값 선택을 하지 않는다. 토큰 수는 공백으로 구분한 형식 명제 토큰이며 특정 언어모델의 토크나이저 토큰이 아니다. 그래프 검색의 기본 결과를 예산 기준으로 썼으므로 학습 삭제가 사용한 더 작은 예산까지 완전히 같게 만든 비교는 아니다. 출력 예산을 맞추어도 전역 점수 계산·그래프 탐색·모델 추론 비용은 서로 다르다. 95% 구간은 최초와 같은 원문 블록 bootstrap으로 기술하며 다중 비교 보정된 확정적 검정으로 해석하지 않는다.
