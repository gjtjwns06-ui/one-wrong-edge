# 기존 검색기의 실패 원인 진단 — 사후 분석 설계

2026-11-23. 기존 `scoped-v1` 시험 결과를 확인한 뒤 사용자의 실패 분석 요청에 따라 추가한다. 기존 설정·분할·모델·원시 결과는 변경하지 않는다. 학습이나 시험 성능에 맞춘 매개변수 선택은 하지 않는다. 아래 비교는 병목을 확인하는 사후 진단이며 새 검색기의 확정적 우월성 평가가 아니다.

## 원리 확인

명제의 결론·필수 가정·변수 제약을 변수 이름 정규화 후 기호 unigram/bigram TF-IDF로 표현한다. 질문과 명제의 코사인 유사도로 앞선 원문 명제 중 상위4개 시드를 고른다. `proof_uses` 방향을 2단계 따라간 뒤 도달 명제를 **동일한 TF-IDF 점수**로 다시 정렬하고 최대20개를 반환한다. 그래프는 후보 집합만 바꾸며 점수나 논리적 타당성을 계산하지 않는다.

## 누락 분해

시험의 모든 질문과 기존 7개 그래프 조건에서 원문 인용 정답을 다음 배타적 항목으로 분해한다. 질문마다 전체 정답 수로 나눈 후 질문 간 평균한다.

1. 실제 Top20에 회수됨.
2. 2단계 후보 안에 있지만 순위 실패 때문에 빠짐. 완벽한 후보 내 재정렬에서 회수 가능한 부분이다.
3. 2단계 후보 안에 있으나 정답 수가 K를 넘어서 생기는 용량상 누락.
4. 현재 방향의 그래프에서 경로는 있으나 최소3단계가 필요함.
5. 현재 방향과 공개된 관계에서는 시드에서 경로가 없음.
6. 검색 허용 규칙으로 배제됨: 원문 순서 또는 동일 질문 서명 제외.

후보 내 정답 수를 g, 전체 정답 수를 m이라 할 때 완벽한 후보 재정렬의 상한은 min(K,g)/m이다. 순위 실패와 용량 누락은 특정 정답을 임의로 지정하는 대신 회수 가능 **개수**로 분해한다. 이 분해는 해당 파이프라인의 정확한 계산 진단이며 현실 수학 질문의 오류 확률을 추정하지 않는다.

## 구조와 점수의 추가 확인

- 시드가 경계 종단·숨긴 증명 출발점·원래 종단·확장 가능한 명제로 구성되는 비율과 탐색이 전혀 안 되는 질문을 센다.
- 정상 그래프에서 시드 1/4/8/16/20개 및 탐색 0/1/2/3/4단계·현재 방향 전체 도달을 비교한다. 원래 범위 밖 노드나 간선은 추가하지 않는다.
- 정상 그래프의 기존 공개 관계를 양방향으로 탐색하는 2단계 진단을 수행한다. 미래 원문 명제와 같은 질문 서명을 계속 제외한다. 후보 크기와 탐색 관계 수 차이도 기록하므로 같은 계산 비용 비교로 해석하지 않는다.
- 정답의 전역 TF-IDF 순위, 시드 안의 정답 비율과 실제 오일러 질의 사례를 조사한다. 정답 인용이 아닌 시드라고 해서 수학적으로 거짓인 명제라는 뜻은 아니다.
- 같은 점수로 재정렬하므로 시드4개는 결과 상위4개에 그대로 남아야 한다. 시드20개·Top20이면 그래프와 무관하게 전역 어휘 Top20과 같아야 한다. 간선 삭제는 후보를 추가할 수 없으므로 2단계 후보가20개 이하인 질문에서 회수율을 높일 수 없어야 한다. 이 불변조건을 확인한다.

오류 시드 17/29/43의 무작위20% 조건은 질문 안에서 평균한다. 불확실성은 기존과 같은 원문 블록 bootstrap 2,000회를 사용하며 기술적 구간으로만 해석한다. 기존 평가의 원문 인용 정답이 대체 증명의 충분성을 평가하지 않는다는 한계도 유지한다.
