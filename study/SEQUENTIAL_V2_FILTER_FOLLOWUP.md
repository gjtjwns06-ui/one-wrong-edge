# 시험 전 추가한 다수 관계 필터 비교

2026-11-23. 1·2단계 선택 완료, OOF0 학습 효과만 확인한 시점에 작성한다. OOF0의 단일 효과37,620개 중 양127개·음248개·0효과37,245개였다. 아직3단계 검증 선택과 새 시험 평가는 하지 않았다.

개선된 검색기에서 개별 간선의 영향이 작을 수 있으므로, 최대1/3개 삭제만으로 ML의 일반적인 추가 가치를 판단하지 않기 위해 **오류 분류 기반 일괄 필터**를 보조 비교로 추가한다. 기존 후보·순위 모델, 주 정책과 원시 결과는 바꾸지 않는다.

- 기존 OOF 귀속 정답으로 학습한 같은 오류 분류기를 사용한다. 새 모델이나 시험 정답을 추가 학습하지 않는다.
- 현재 질문의 관측 탐색 간선 전체를 점수화한다. 임계값0.5/0.7/0.9/1.01과 최대24/64/128개 억제를 검증 자료에서 비교한다.1.01은 보류다.
- 각 조합의 최종 후보·특징·순위를 실제 재계산한다. 개별 효과를 더하지 않는다. 검증 Recall@20 변화와 삭제 수로 선택한다.
- 같은 수의 관측 탐색 관계를 지우는 무작위 비교군을 둔다. 정답·주입 표시로 삭제 후보를 고르지 않는다.
- 기존 단일 효과 오라클은 최대24개 후보에 한정된 비교이므로 이 일괄 필터의 상한이 아니다. 더 큰 행동/특징 계산 예산을 사용한다는 사실을 구분한다.

이 추가 비교 역시 이전 시험 자료를 재사용하는 개발 평가의 일부다. 새 시험 결과를 보고 추가한 비교가 아니며, 원래 최대1/3개 비교와 별도로 보고한다.
